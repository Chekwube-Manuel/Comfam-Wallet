# Confam Wallet

A non-custodial Ethereum wallet in a single Python CLI. Keys are generated on
your machine, stored in a password-encrypted Web3 V3 keystore, and every
signature is produced locally. The network is only contacted for public reads
(nonce, gas, balance) and to broadcast already-signed raw transactions — no
key material ever leaves the machine.

## Requirements

- Python 3.9+

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Configuration

| Variable         | Default                    | Purpose                          |
| ---------------- | -------------------------- | -------------------------------- |
| `CONFAM_RPC_URL` | `http://127.0.0.1:8545`    | Ethereum JSON-RPC endpoint       |

## Usage

### Create a wallet

```bash
.venv/bin/python cli.py create --keyfile .keys/me.json --password "s3cret"
```

The key is generated locally and only the encrypted keystore is written.
The address is printed; back up the keyfile and password now.

### Import an existing private key

```bash
.venv/bin/python cli.py import-key \
  --private-key 0xYOUR_PRIVATE_KEY \
  --keyfile .keys/me.json --password "s3cret"
```

> Never commit private keys. The CLI can keep the password out of your shell
> history by prompting hidden if you omit `--password`.

### Show the address

```bash
.venv/bin/python cli.py address --keyfile .keys/me.json --password "s3cret"
```

### Check a balance

```bash
.venv/bin/python cli.py balance --keyfile .keys/me.json --password "s3cret"
```

### Sign a message (EIP-191 `personal_sign`)

```bash
.venv/bin/python cli.py sign-message \
  --keyfile .keys/me.json --password "s3cret" \
  --message "hello confam"
```

### Verify a message signature

```bash
.venv/bin/python cli.py verify-message \
  --address 0x... \
  --signature 0x... \
  --message "hello confam"
```

Prints `VALID` and exits 0 if the signature recovers to the given address,
otherwise prints `INVALID` and exits 1.

### Send ETH (build, sign locally, broadcast)

```bash
.venv/bin/python cli.py send-tx \
  --keyfile .keys/me.json --password "s3cret" \
  --to 0xRecipient \
  --amount "0.01 ether"
```

Amounts accept `wei`, `gwei`, or `ether` units.

## Tests

```bash
.venv/bin/python -m unittest
```

The test suite covers keystore creation, address recovery, message
sign/verify, and `send-tx` signing against a stubbed JSON-RPC transport.

## Security model

- **Non-custodial**: the private key is generated by the OS CSPRNG and never
  transmitted. Only the AES-encrypted keystore is stored.
- **Local signing**: `personal_sign` and transaction signing happen in-process
  on this machine.
- **Minimal network surface**: the only outbound calls are `eth_getBalance`,
  `eth_getTransactionCount`, `eth_gasPrice`/`eth_estimateGas`, and
  `eth_sendRawTransaction` (with an already-signed blob).
